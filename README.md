# Digital Marketing Chatbot (Streamlit)

## Setup
1. `pip install -r requirements.txt`
2. Copy `.streamlit/secrets.toml.example` to `.streamlit/secrets.toml` and add your Gemini API key
   (or set the `GEMINI_API_KEY` environment variable, or paste it in the app sidebar).
3. Run: `streamlit run app.py`

Edit `knowledge_base.txt` to change what the chatbot knows.
